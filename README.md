# quirky-kettle-lite

Backend developer · Java and Spring · archiving old docs

给自己省点事的小工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/quirky-kettle-lite.git
cd quirky-kettle-lite
npm install
```
